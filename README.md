# 练 · 训练打卡

一个**单文件**的力量训练打卡器。手机浏览器打开就能用，可以「添加到主屏幕」当 App 用；训练记录全部存在你自己的手机里，不联网、不上传、不用注册。

> 为「不想跟视频练、只想按组数走完」的人做的。做完一组点一下，休息倒计时自动开始，休息完再点一下，做完一组点一下 —— 全程只需要拇指。

## 它解决什么

市面上多数训练 App 是「跟着视频做」，节奏由视频决定，还要暂停、回看、拖进度条。这个工具反过来：**计划是你自己的，节奏由你的手指决定**。

- 不需要器械、不需要场地，也不依赖网络
- 没有教程、没有弹窗、没有会员
- 只有四个东西：今天练什么、下一组是什么、还剩几秒、这周落了几次

## 功能

**训练流程**

- 按星期几排期，打开就知道今天练什么；休息日直接告诉你休息，不推你练
- 大字号显示动作名、第几组/共几组、目标次数
- 点「完成这一组」→ 记录，并自动进入组间歇倒计时（圆环 + 最后 3 秒滴答 + 结束提示音 + 震动）
- 休息中可「跳过休息」「+15 秒 / +30 秒」
- 计时类动作（平板支撑、慢跑）点开始自动倒数，到点自动记账
- 点错了可以**撤销上一组**
- 训练时屏幕不熄灭（Wake Lock）；切后台再回来，倒计时按真实时间补算，不会走偏

**计划**

- 内置一套无器械力量计划，也可以导入自己的 JSON
- 计划详情里每个动作后面有 −/+，直接改组数、次数、休息秒数，改完自动存成你自己那份
- 可导出当前计划

**记录**

- 训练次数 / 累计组数 / 累计分钟、近 12 周热力图
- 每条记录可展开看每组做了多少，可删除、可改归属日期
- 一键导出全部记录，也可从备份文件恢复（按 id 去重合并，重复导入不会翻倍）

**训练语录**

- 训练页与组间歇会显示一句短语，按完成度分四档，从「纪律」到「绝不投降」逐步加重
- 抽取是**有状态**的：当天不重句；昨天用过的今天权重最低；屏幕上正在显示的那句直接排除 —— 所以每次训练 ↔ 休息切换必定换新
- 可在设置里一键关掉

## 怎么用

**方式一：直接打开**

下载 `index.html`，用浏览器打开。

⚠️ 但 `file://` 协议下浏览器的存储身份是空源，各机型对 localStorage 的政策不一致，**记录可能存不住而且不报错**。iOS 上从「文件」App 打开 html 多半只当文本预览、不执行 JS。所以只建议用来试用。

**方式二：放到静态托管上（推荐）**

把仓库根目录整个放到任何静态托管（GitHub Pages / Vercel / Netlify / 自己的服务器）即可，无需构建、无需后端。

手机浏览器打开链接 → 分享 → **添加到主屏幕**。之后从图标进入是全屏、无地址栏的，和原生 App 没有区别，并通过 Service Worker 缓存，断网也能打开。

## 数据与隐私

- 所有数据在 `localStorage`（键 `train.v1`），**不上传任何东西**
- 页面不加载任何外部资源（无 CDN、无统计脚本、无字体外链），断网可用
- 换手机或清缓存前，请先在「记录 → 设置」里导出备份

## 文件

```
index.html            整个应用（HTML + CSS + JS，零依赖）
manifest.webmanifest  PWA 清单
sw.js                 Service Worker，仅缓存外壳
icon.svg / icon-*.png 图标
```

没有构建步骤。改完 `index.html` 刷新即可。
